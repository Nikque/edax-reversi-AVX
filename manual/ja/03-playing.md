# 3. 対局と解析のコマンド

[目次](README.md) ｜ 前：[2. 起動と最初の対局](02-quick-start.md) ｜ 次：[4. 設定](04-settings.md)

この章は、対局と解析に使うコマンドの説明です。book のコマンド（`book …`）は [6](06-book-basics.md)〜[8 章](08-book-maintenance.md)、棋譜のファイルをまとめて扱うコマンド（`base …`）は [10 章](10-files.md)にあります。

コマンドは、`>` の後に打って Enter を押します。多くのコマンドには短い名前があります（`undo` は `u` など）。画面で `help`（または `?`）と打つと、Edax に組み込まれた英語の一覧が出ます（v4.5.5-nikque.12 までの版では、この一覧の「既定値」の一部が、古い版の値のままでした。正しい既定値は [4 章](04-settings.md)と [14 章](14-reference.md)にあります）。

## 3.1 手を打つ

| 入力 | 意味 |
|---|---|
| `f5`（マスの名前） | そのマスに打つ。大文字でも小文字でもよい |
| `ps`（または `pa`、`pass`） | パスする（打てるマスがないときだけ） |
| `play f5d6c3d3c4` | 手順をまとめて打つ。手と手の間に空白を入れてもよい。パスは書かなくても、必要なところで自動的に入る |
| `play tiger` | 定石の名前（英語）で、その手順を打つ |
| `go` | 今の手番の手を、Edax に 1 手打たせる |
| `stop` | Edax が考えているのを止める（そこまでに見つけた手を打ち、`mode 3` になる） |

`play` は、今の局面から続けて打ちます。初期局面から打ち直したいときは、先に `init` を打ちます。

**定石の名前**：`play tiger` のように、Edax が知っている定石の名前（英語）を `play` に渡せます。逆に、今の局面の定石の名前は `opening`（英語）・`ouverture`（フランス語）で表示できます（名前の付いていない局面では `?` と表示されます）。

```
>play tiger
>opening
tiger
>ouverture
tigre
```

## 3.2 対局の進め方を決める：mode

| 入力 | 黒 | 白 |
|---|---|---|
| `mode 0` | 自分 | Edax |
| `mode 1` | Edax | 自分 |
| `mode 2` | Edax | Edax |
| `mode 3`（起動時） | 自分 | 自分 |

- `mode 2` は、今の局面から終局まで、Edax どうしで打ち進めます。
- `mode 3` では、Edax は自分からは打ちません。局面を並べて `hint` で調べる、`go` で 1 手ずつ打たせる、という使い方に向いています。
- `m` は `mode` の短い名前です。数字を省くと `mode 3` になります。

## 3.3 戻る・進む・やり直す

| 入力 | 意味 |
|---|---|
| `undo`（`u`） | 1 手戻す。`mode 0`・`mode 1` のときは 2 手（自分の手と Edax の手）戻す |
| `redo`（`r`） | 戻した手を、もう一度進める（同じく `mode 0`・`mode 1` では 2 手） |
| `init`（`i`） | ふつうの初期局面にして、新しい対局を始める |
| `new`（`n`） | 今の対局の「最初の局面」から、新しい対局を始める。`setboard` で作った局面や、読み込んだ棋譜の最初の局面から打ち直すときに使う |

## 3.4 調べる：hint と analyze

### hint：今の局面の良い手

```
>hint 3
```

今の局面の良い手を、評価値の高い順に 3 つ表示します（1〜60。省くと 1）。表の読み方は [2.5](02-quick-start.md) と [5 章](05-search.md)にあります。打てる手の数より大きい数を指定すると、全部の手を表示します。

`hint` は局面を変えません。探索の強さは、今の `level` です。book を使う設定で、今の局面が book にあるときは、book に記録されている手が先に表示されます（`depth` の欄が `book` の行。[6.5](06-book-basics.md)）。

### analyze：打ち終えた棋譜を振り返る

```
>analyze 6
```

今の対局の**最後の 6 手**を、終わりのほうから 1 手ずつ調べ、「実際に打った手」と「ほかの手のうち最善のもの」を比べます（数字を省くと、全部の手）。強さは今の `level` です。手数が多いと時間がかかります。

```
              N     played        alternative
ply  level   alt. move  score     score   move
---+-------+-----+-----------+--+---------------
 60    0      0    a3    +14
 59    2      1    A2    -14   >   -26     A3
 58    2      0    g2    +14
 57    4      3    H2    -14   >   -24     G2
 56    2      2    b1    +14   >    +5     g2
 55    2      5    A1    -14   >   -16     H2

      | rejections : discs | errors    : discs | error rate |
Black |   0 /   1  :    +0 |   0 /   2 :    +0 |      0.000 |
White |   0 /   1  :    +0 |   0 /   0 :    +0 |          - |
```

| 欄 | 意味 |
|---|---|
| `ply` | 何手目か |
| `level` | その手を調べた深さ（`18@73%` のような形。[5 章](05-search.md)） |
| `N alt.` | ほかに打てた手の数 |
| `played` の `move`・`score` | 実際に打った手と、その評価値（この欄では、黒の手が大文字、白の手が小文字） |
| まん中の印 | `>`：打った手のほうが良い、`=`：同じ、`<`：ほかの手のほうが良い |
| `alternative` の `score`・`move` | ほかの手のうち最善のものと、その評価値 |

ほかの手のほうが良かったときは、行の右に次の言葉が付きます。

| 言葉 | 意味 |
|---|---|
| `<- Mistake` | 完全読みで確かめた悪手 |
| `<- Possible mistake` | 最後まで読んだが、確かさが 100% でない探索での判定 |
| `<- Edax disagrees`（差が 5 石以上なら `strongly`） | 中盤の探索による判定（確定ではない） |

下の 2 行は、黒と白それぞれのまとめです。`rejections` は完全読みでない探索で「ほかの手のほうが良い」となった数（／調べた数）と石数の合計、`errors` は完全読みで確かめた悪手の数（／完全読みで調べた数）と石数の合計、`error rate` は完全読みで調べた 1 手あたりの失った石数です。完全読みで調べた手が 1 つもない色の `error rate` は、`-`（横線）です（v4.5.5-nikque.12 までは、`-nan(ind)` のような、数でない表示が出ていました）。

**book を使った振り返り**：`book analyze 6` は、同じことを、探索ではなく book の評価値で行います（book に入っている局面だけ。[6 章](06-book-basics.md)）。

## 3.5 局面を作る：setboard

好きな局面から始めるには、`setboard` に、盤の 64 マスと手番を渡します。

```
>setboard -------- -------- -------- ---OX--- ---XO--- -------- -------- -------- X
```

- 盤は、A1、B1、…、H1、A2、…、H8 の順に 64 マスぶん書きます。
- 黒石は `X`（または `*`、`b`）、白石は `O`（または `w`）、空きは `-`（または `.`）です。それ以外の文字（空白など）は読み飛ばされるので、上の例のように 8 マスごとに空白を入れて書けます。
- 64 マスの後に、手番を 1 文字で書きます（`X`＝黒番、`O`＝白番）。
- **マスの数が 64 に足りないと、手番の文字までマスとして読まれてしまいます**。そのときは `WARNING: board_set: bad string input` と表示され、手番は Edax が決めます（空きマスの数が偶数なら黒番、奇数なら白番）。数え間違いに注意してください。

`setboard` の後は、その局面が「最初の局面」になります。`new` で、その局面からやり直せます。`init` で、ふつうの初期局面に戻ります。

### 盤を裏返す・回す

今の対局（打った手順ごと）を、対称な形に移します。

| 入力 | 意味 |
|---|---|
| `vmirror` | 上下を入れ替える |
| `hmirror` | 左右を入れ替える |
| `rotate 90`（`180`、`270`） | 回す |
| `symetry n`（`n` は 0〜15） | 8 通りの対称を番号で指定する。8 以上は、さらに手番も入れ替える |

## 3.6 棋譜を保存する・読み込む

```
>save mygame.txt
>load mygame.txt
```

`save`（`s`）は今の対局を保存し、`load`（`o`、`open`）は棋譜を読み込んで、その最後の局面まで進めます。**形式は、ファイル名の終わり（拡張子）で決まります。**

| 拡張子 | 形式 | 保存 | 読み込み |
|---|---|---|---|
| `.txt` | 手順を 1 行に並べた文字（`F5D6C3D3C4`） | ○ | ○ |
| `.sgf` | SGF | ○ | ○ |
| `.ggf` | GGF（GGS の棋譜の形式） | ○ | ○ |
| `.pgn` | PGN | ○ | ○ |
| `.edx` | Edax 独自のバイナリー | ○ | ○ |
| `.eps`・`.svg` | 盤の図（画像） | ○ | × |

- ファイル名は、今いるフォルダー（`bin`）から見た場所です。`save games/mygame.txt` のようにフォルダーも書けます（フォルダーは、先に作っておきます）。
- 知らない拡張子では、`WARNING: Unknown game format extension: .abc` と表示されて、何も保存されません。
- 読み込みに失敗したときは、理由が表示されて、局面は変わりません（`WARNING: Cannot open file nofile.txt`、`WARNING: Unknown game format extension: .abc`、`WARNING: Illegal move #2: A1` など）。v4.5.5-nikque.12 までの版では、何も表示されませんでした。
- **途中の局面から始めた対局（`setboard` の後）は、`.ggf`・`.pgn`・`.edx` で保存してください。** `.txt` と `.sgf` は、保存はできますが、読み戻せません（[10.1](10-files.md)）。
- 打てない手を含む棋譜は、読み込まれません。盤は、読み込む前のままです（`.ggf`・`.sgf`・`.pgn` では、`WARNING: error while importing a GGF game` のような警告が出ます）。`.txt` だけは、警告を表示して、打てない手の手前までが読み込まれます。v4.5.5-nikque.12 までの版では、石を 1 つも返せない手が、そのまま盤に置かれて読み込まれていました（[10.1](10-files.md)）。
- 棋譜の形式は、[10 章](10-files.md)にまとめてあります。

## 3.7 Edax に決まった序盤を打たせる：force

```
>force f5d6c3
```

これ以降、Edax は、局面がこの手順（と、その対称な形）の上にある間、自分の番ではこの手順どおりに打ちます。手順が終わるか、相手が手順を外れると、ふつうに考えて打ちます。定石の名前も書けます（`force tiger`）。

- 手順は、今の対局の「最初の局面」からのものとして読まれます。
- `init` を打つと、指定は「1 手目は F5」に戻ります（起動した直後も同じです。初期局面の 4 つの手は対称で同じなので、Edax は黒番の 1 手目を、考えずに F5 と打ちます）。`setboard` を打つと、指定はなくなります。

## 3.8 強さと時間

| 入力 | 意味 |
|---|---|
| `level 12` | 探索の強さを 12 にする（0〜60。[5 章](05-search.md)） |
| `game-time 5:00` | 1 局の持ち時間を 5 分にする（片方ぶん）。Edax は、残り時間を見ながら考える時間を決める |
| `move-time 10` | 1 手の時間を 10 秒にする |
| `ponder on`／`ponder off` | 相手の番の間も考えるかどうか（既定は on） |

- 時間は、`秒`、`分:秒`、`時:分:秒` の形で書きます（`30`、`5:00`、`1:30:00`）。
- `game-time`・`move-time` を指定すると、Edax は level ではなく**時間**で考えます。このとき、`level`（コマンドか、コマンドラインの `-l`）を**自分で指定していれば**、その level が読みの上限になります。指定していなければ、時間の許すかぎり深く読みます（`config.ini` に書いた `level` は、上限になりません）。
- `level` を打つと、時間ではなく level で考える状態に戻ります。
- 対局の途中で `game-time` を変えたときは、次の対局（`init`・`new`）から、その持ち時間になります。
- 起動のときに決めるなら、コマンドラインで `-t 5:00`（`-game-time` と同じ）、`-move-time 10` と書きます。

持ち時間 20 秒で起動した例です（`options` の表示の一部）。

```
	search alloted time: 0:20.000
	search with: fixed time per game
```

## 3.9 続けて何局も打つ

次の設定は、終局したときの動作を決めます（どれも既定は `off`。`auto-start on` のように打つか、起動のときに `-auto-start on` と書きます）。

| 設定 | 終局したときの動作 |
|---|---|
| `auto-start on` | 自動で新しい対局を始める |
| `auto-swap on` | Edax の持つ色を入れ替える（`mode 0` ↔ `mode 1`） |
| `auto-store on` | その対局を book に入れる（`book store` と同じ。[7 章](07-book-learning.md)） |
| `auto-quit on` | Edax を終了する |
| `repeat n` | n 局打つ（起動のときの `-repeat n`） |

今の値は、`options` コマンドの表示のいちばん最後（`Game play` の下）で確かめられます。次は、`-auto-store on -auto-swap on` で起動したときの表示です（上から順に、`mode`、`auto-start`、`auto-store`、`auto-swap`、`auto-quit`、`repeat`）。

```
Game play
	mode: human/human
	start a new game after a game is over: false
	store each played game in the opening book: true
	change computer's side after each game: true
	quit when game is over: false
	repeat 0 games (before exiting)
```

- `mode:` の行は、**起動のときの値**（`-mode` や `config.ini` の `mode`）です。実行中に `mode 0` などと打っても、この行は変わりません（今の mode は、Edax が自分で打つかどうかで分かります）。
- v4.5.5-nikque.12 までの版では、`auto-store`・`auto-swap`・`auto-quit` の行に、どれも `auto-start` の値が表示されていました（表示だけの不具合で、動作は設定どおりでした）。

## 3.10 表示を変える

| 入力 | 意味 |
|---|---|
| `verbose 0` | 盤と探索の表を表示しない（`You play …`・`Edax plays …` は表示される）。起動のときの `-q` と同じ |
| `verbose 1` | ふつうの表示（既定） |
| `verbose 2` | 探索の途中経過も表示する（深さが 1 つ進むたびに 1 行）。起動のときの `-vv` と同じ |
| `noise n` | 探索の途中経過のうち、深さが n より浅いものを表示しない |
| `width n` | 探索の表の横幅（文字数。既定は 80） |
| `options` | 今の設定を全部表示する |
| `version`（`v`） | 版を表示する |
