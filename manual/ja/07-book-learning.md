# 7. book を育てる

[目次](README.md) ｜ 前：[6. book の基礎](06-book-basics.md) ｜ 次：[8. book の保守](08-book-maintenance.md)

book に局面を足していくことを、このマニュアルでは「育てる」と言います（Edax の言葉では「学習」）。育て方は、大きく 2 つあります。

| 育て方 | コマンド | 向いている場面 |
|---|---|---|
| **棋譜から**：打った対局・棋譜のファイルの局面を book に入れる | `book store`・`book add`・`book learn` | 自分の対局や、強い人・強いプログラムの棋譜を取り込む。調べたい定石を入れる |
| **自動で広げる**：book の中の「良さそうな Leaf」を、Edax が自分で選んで広げる | `book deviate`・`book deviate2`・`book deviate3`・`book enhance`・`book fill`・`book play` | book を、評価値の良い変化に沿って、広く・深くしていく |

実際には、両方を組み合わせます（棋譜で骨組みを入れ、自動で広げる）。

**始める前に**：[6.6](06-book-basics.md)（どのファイルが読まれ、どこへ保存されるか）と [6.7](06-book-basics.md)（`book new` と、それまでの book のファイル）を読んでください。

## 7.1 まず小さい book で試す

大きな book を育てる前に、低い level の小さい book で、コマンドの動きを見ておくことをおすすめします。次の例は、1 分ほどで終わります（表示は実際の出力です。数字は、PC と実行のたびに少し変わることがあります）。

新しい名前の book のファイルを指定して起動します（`data/my.dat` は、まだ存在しない名前。`-n 2` は 2 スレッド、`-l 8` は level 8）。

```
wEdax-x86-64.exe -book-file data/my.dat -n 2 -l 8
```

level 8・深さ 12 の book にして、自動で広げます。

```
>book new 8 12
New book 8 49......done>

>book deviate 1 2
Book deviate 1 2:
Book deviate 1 todo
Book deviate...
Book deviate...1/1 done: 1 positions, 1 links
 …（何周も繰り返す）…
Book deviate 1 2...finished

>book info
Edax Book 4.5; 2026-10-7 17:10:44;
Positions: 110 (moves = 111 links + 108 leaves);
Level 8 : 110 nodes
Depth: 12
```

1 局面だった book が、110 局面になりました。条件を広げた別のコマンドで、もっと広げます。

```
>book deviate2 2 4
Book deviate2 2 4:
Book deviate2 32 todo
Book deviate2...
Book deviate2...1/32 done: 1 positions, 1 links
 …
Book deviate2 2 4...finished

>book info
Positions: 1952 (moves = 1989 links + 1949 leaves);
```

`quit` で終了すると、book は `data/my.dat` に保存されます。途中経過のファイル `data/my.dat.dev`・`data/my.dat.dev2` もできています（[6.6](06-book-basics.md)）。

## 7.2 棋譜から育てる

### book store：今の対局を入れる

盤の上で打った対局（`play` で並べた手順でもよい）を、book に入れます。

```
>play f5d6c3d3c4
>book store
Searching positions...
Searching positions...2 done
Linking book...
Linking book...3 done
Negamaxing book...done
```

- 対局の局面のうち、book の深さの範囲のもの（と、そのすぐ先の、いちばん深い層になる局面）を、**終わりのほうから順に**探索して book に足します。それより先の局面は入りません。途中までの対局でもかまいません。
- 足した後、Link の張り直しと negamax を行い、`<book のファイル名>.store` に保存します。
- 設定 `auto-store on` にしておくと、対局が終局するたびに、自動で `book store` が行われます（[3.9](03-playing.md)）。

### book add：棋譜のファイルを入れる

```
>book add games.txt
Adding 3 games to book...
Searching positions...
Searching positions...4 done
Adding games...3/3 done: 3 positions, 3 links
```

棋譜のファイル（形式は拡張子で決まる：`.txt`・`.ggf`・`.sgf`・`.pgn`・`.wtb`・`.edx`。[10 章](10-files.md)）の全部の対局を、`book store` と同じように入れます。結果は `<book のファイル名>.gam` に保存されます。

`.txt` の場合は、1 行に 1 局、手順を続けて書きます。

```
f5d6c3d3c4f4c5b3c2
f5f6e6f4e3c5c4e7c6e2
```

### book check：棋譜を book と比べる（book は変えない）

```
>book check games.txt
Checking 3 games to book...
Positions : 0 missing, 20 good, 4 bad (16.67% bad)
```

棋譜の中の「局面と、そこで打たれた手」を、book と比べて数えます（book の深さの範囲だけ。ふつうの初期局面から始まる棋譜だけ）。

| 言葉 | 意味 |
|---|---|
| `missing` | 局面が book にない |
| `good` | 打たれた手が、book の最善の手（と同じ評価値） |
| `bad` | 打たれた手が、book に記録されているが、最善より悪い |

### book learn：途中までの手順から、Edax に終局まで打たせて入れる

```
>book learn learn.txt
Playing games...
Playing games...2 done
Searching positions...
Searching positions...5 done
Linking book...
Linking book...2253 done
Negamaxing book...done
 …
3/3 games learned
```

ファイルの 1 行ごとに、「その手順を打つ → そこから Edax どうしで終局まで打つ → その対局を `book store` する」を行います。調べたい序盤の手順を並べておけば、その先を Edax が打ち継いで、book に入れてくれます。

ファイルの書き方：

```
f5d6c4
2,f5f6e6f4e3
# ここは説明の行
f5f4e3
```

- 1 行に 1 局。手順を続けて書きます（空白を入れてもよい）。
- `2,手順` のように、頭に数とコンマを書くと、その対局だけ、book から打つときの幅（`book-randomness`）をその数にします。
- 空の行、`#` で始まる行、`//` を含む行は、読み飛ばされます。
- 打ち継ぎは、今の `level` で行われます。book にある局面では、book の手を打ちます（`book on` のとき）。
- 最後に `N/M games learned`（M 行のうち N 局を学習した）と表示されます。打てない手のある行は、警告が出て、学習されません。
- 結果は `<book のファイル名>.store` に保存されます。

### 棋譜の学習を同時に行う：book-store-tasks

`book store`・`book add`・`book learn` は、設定 `book-store-tasks` で、**複数の棋譜（の局面の探索）を同時に**進めます。

| `book-store-tasks` | 動作 |
|---|---|
| `auto`（既定） | `n-tasks` 本の棋譜を同時に学習する（1 本につき 1 スレッド）。いちばん速い |
| 数 n（2 以上） | n 本を同時に学習する（1 本につき `n-tasks ÷ n` スレッド） |
| `1` | 局面を 1 つずつ、全部のスレッドで探索する（元の Edax と同じ動作。できる book も同じ） |

- 配布物の README の実測（論理 CPU 32、level 18、棋譜 128 本）では、`auto` が `1` の 2.8〜3.3 倍の速さでした。
- `auto` でできる book は、`1` でできる book と、まったく同じにはなりません（一部の Leaf の手と評価値が、1〜2 石違うことがあります）。違いの大きさは、探索のスレッドの数を変えたときと同じ程度です。元の Edax と同じ book が必要なときだけ、`1` にしてください。
- `book learn` は、`book-store-tasks` 本ずつをひと組にして、同時に対局します。同じ組の中の棋譜は、互いの学習の結果を使わずに対局します（組が終わるたびに、まとめて book に入ります）。

## 7.3 自動で広げる：book deviate の仲間

### しくみ

これらのコマンドは、**今の盤の局面から**始めて、book の Link をたどり、条件に合う **Leaf を選んで広げます**。「広げる」とは、その Leaf の手を打った先の局面を探索して book に足し（Leaf が Link になる）、元の局面には、残りの手の中から次の Leaf を探索して付けることです。1 つ広げるごとに、探索を 2 回行います。

1 回の流れ（これを「1 周」と呼びます）：

1. negamax（評価値を最新にする）
2. 条件に合う Leaf を全部選ぶ。選んだ数が `todo` と表示される
3. 選んだ Leaf を、1 つずつ（または同時に）広げる
4. negamax して、決まった間隔で保存する

広げた結果、評価値が変わって、新しい Leaf が条件に合うようになるので、**何も増えなくなるまで、周を繰り返します**。終わると `...finished` と表示されます。条件を広く取ると、周は何百回も続き、時間は何時間・何日にもなります。

- 始める局面は、**今の盤**です。初期局面から全体を広げるなら `init` を打ってから、ある定石だけを掘るなら `play f5d6c3` のように進めてから、コマンドを打ちます。
- **今の盤の局面が book に入っていないと、コマンドは何もしません**（何も表示されずに、すぐ `>` に戻ります）。book にない局面から始めたいときは、先に `book store` で、そこまでの手順を book に入れます。
- book の深さ（[6.4](06-book-basics.md)）より先には広げません。
- 表示の `Book deviate2...11/32 done: 11 positions, 11 links` は、「選んだ 32 個のうち 11 個を広げ終えた。この周で局面が 11、Link が 11 増えた」という意味です。

### 3 つのコマンドの条件

どれも数を 2 つ取ります。

| コマンド | 1 つ目の数 | 2 つ目の数 | 完全読みの局面の Leaf |
|---|---|---|---|
| `book deviate X Y` | 「片方の側」が最善から外れてよい石数（相対誤差） | 始めた局面の評価値から離れてよい石数（絶対誤差） | 広げる |
| `book deviate2 X Y` | 1 手で失ってよい石数（どちらの側も） | 始めた局面からそこまでに、**両方の側が失った石数の合計**の上限 | **広げない** |
| `book deviate3 X Y` | `deviate2` と同じ | `deviate2` と同じ | 広げる |

数を省くと、どれも `2 4` です。

**book deviate X Y**（元の Edax からある方法）：1 周の中で、選択と展開を 2 回行います。1 回目は「始めた局面の手番の側は、最善より X 石まで悪い手も選ぶ。相手は最善の手だけ」という手順をたどり、2 回目は、その逆です。どちらも、評価値が「始めた局面の評価値 ± Y」の範囲にある手だけを対象にします。つまり「**片方だけが少し間違え、もう片方は正しく打つ**」変化を広げます。

**book deviate2 X Y**（この修正版で足した方法）：手を 1 つ選ぶたびに、「その局面の最善の手との評価値の差」を「失った石数」として数えます。**1 手で失うのは X 石まで、始めた局面からの合計（黒と白を合わせて）が Y 石まで**の手順をたどり、その範囲の Leaf を広げます。

`deviate2 5 5` の例：

| 手順の中の失点 | 範囲の中か |
|---|---|
| 黒が 2 石、白が 3 石（合計 5） | 中 |
| 1 手で 5 石（合計 5） | 中 |
| 1 手で 6 石 | 外（1 手の上限を超える） |
| 黒が 3 石、白が 3 石（合計 6） | 外（合計の上限を超える） |

`deviate2` は、**完全読みの局面の Leaf を広げません**（その局面の level で、空きの数が完全読みの範囲に入っている局面。level 18 なら空き 21 以下）。完全読みの局面は、Leaf の評価値がすでに正確なので、その先を book に足しても、評価値は変わらないからです。book の終わりの層を無駄に広げずに済みます。

**book deviate3 X Y**：条件は `deviate2` と同じで、完全読みの局面の Leaf も広げます。

### どれを使うか・数の決め方

- **ふつうは `book deviate2`** をおすすめします。「両方の側の間違いの合計」で範囲を決めるので、対局で実際に現れる変化を、偏りなく広げられます。
- 数を大きくすると、対象が急に増えます。上の小さい book（level 8・深さ 12）では、`deviate 1 2` で 110 局面、続けて `deviate2 2 4` で 1,952 局面になりました（**小さい book での数で、大きな book での見込みにはなりません**）。最初は小さい数（`1 2`、`2 4`）から始め、時間と局面の数を見ながら広げてください。
- 途中で止めても、そこまでに保存された分は残ります（下の 7.5）。同じコマンドをもう一度打てば、続きから広げます（すでに広げた Leaf は、もう Link になっているので、選ばれません）。

## 7.4 自動で広げる：そのほかのコマンド

| コマンド | 意味 | 途中経過のファイル |
|---|---|---|
| `book enhance X Y` | 評価値の下限・上限を使って、「探索の誤差（中盤の探索で X 石、終局まで読むが 100% でない探索で Y 石）を見込むと、局面の評価値を変えるかもしれない Leaf」を広げる。変わるものがなくなるまで繰り返す。数を省くと `2 4` | `.enh` |
| `book fill n` | book の局面から n 手進めた先が、book の中の別の局面になるとき、その途中の局面と Link を足す。増えるものがなくなるまで繰り返す。`book fill 1`（数を省いたとき）は、欠けている Link が張られるだけで、局面は増えない | `.fill` |
| `book play` | Link を 1 つも持たない局面（手順の先端）の Leaf を広げる。これを、そういう局面が book の深さの範囲からなくなるまで繰り返す。つまり、**どの手順も、最善の手で book の深さまで伸ばす** | `.play` |

これらは、元の Edax からあるコマンドです。この修正版では、動作の確認（以前の版と同じ book ができること）は行っていますが、大きな book での使い方の実績は `book deviate` 系ほどありません。まず小さい book で、何が起きるかを見てから使ってください。

小さい book での表示の例です。

```
>book play
Book play...153 todo
Book play...
Book play...1/153 done: 1 positions, 1 links
 …
```

## 7.5 途中の保存と、止め方

自動で広げるコマンドは、長く動きます。**止まったとき（停電、PC の再起動、自分で止めた）に失うのは、最後に保存した後の分**です。保存の間隔は、2 つの設定で決めます。

| 設定 | 配布物の値 | 意味 |
|---|---|---|
| `book-save-interval` | 360（分） | 展開の途中で、この時間ごとに保存する。`0` は、時間では保存しない |
| `book-deviate-save-rounds` | 1 | `book deviate` 系で、局面や Link が増えた周を、この数だけ終えるごとに保存する。`0` は、コマンドが終わったときだけ |

- 保存先は、`<book のファイル名>.dev2` など（[6.6](06-book-basics.md)の表）です。`book.dat` そのものは、コマンドの途中では書き換えられません。
- 大きな book では、1 回の保存に時間とディスクの空きが要ります（[9 章](09-large-books.md)）。周が短いのに毎周保存すると、保存ばかりしていることになります。そのときは `book-deviate-save-rounds` を大きくします（例：10）。逆に、1 周が何時間もかかるなら、`book-save-interval` を短くします。
- **`0` と `0` の組み合わせ（どちらの保存もしない）は、コマンドが終わるまで何も保存されません。** 途中で止まると、全部を失います。

**止め方**：book のコマンドは、途中でやめる入力を受け付けません。

- `stop` と打っても、止まりません（v4.5.5-nikque.13 から。「何も止めなかった」という表示が出ます。それより前の版では、探索中の 1 局面だけが打ち切られ、途中の結果が book に入っていました）。
- `quit` と打つと、**コマンドが終わってから**終了します。
- すぐに止めたいときは、Edax のプログラムそのものを止めます（ウィンドウを閉じる、Ctrl+C を押す）。メモリの中の book は失われ、残るのは、最後に保存されたファイルです。保存の途中で止めても、書きかけのファイルが本物と入れ替わることはありません（[6.6](06-book-basics.md)の「保存のしくみ」）。

**止めた後の続け方**：最後の途中経過のファイル（例：`data/book.dat.dev2`）のほうが `data/book.dat` より新しいはずです。次のどちらかで続けます。

- ファイルの名前を変える：`book.dat` を別の名前にして残し、`book.dat.dev2` を `book.dat` に変えてから、Edax を起動する。
- 起動してから `book load data/book.dat.dev2` を打つ（この場合も、自動の保存先は `book-file` です。[6.6](06-book-basics.md)の注意 2）。

そのうえで、同じコマンド（`book deviate2 5 5` など）をもう一度打ちます。

## 7.6 同時に広げる：book-expand-tasks

低い level の探索は短いので、1 つの探索に多くのスレッドを使っても、あまり速くなりません（[5.5](05-search.md)）。設定 `book-expand-tasks` で、**複数の Leaf を同時に**広げると、CPU を使い切れます。`book deviate`・`deviate2`・`deviate3`・`enhance`・`play` に効きます。

| `book-expand-tasks` | 動作 |
|---|---|
| `1`（`config.ini` がないときの値） | 1 つずつ、全部のスレッドで探索する。元の Edax と同じ動作 |
| 数 n | n 個を同時に広げる。1 つの探索は `n-tasks ÷ n` スレッド |
| `auto`（配布物の `config.ini` の値） | book の level から決める：level 18 以下は 1 つの探索に 2 スレッド、24 以下は 4、それより上は 8（同時に広げる数は、`n-tasks` をそれで割った数）。さらに、level 18 以下で、その周の対象が `n-tasks` の 32 倍以上あるときは、1 スレッドの探索を `n-tasks` 個同時に動かす |

- 配布物の README の実測（論理 CPU 32、level 18、6 億 5,688 万局面の book、`book deviate3 2 5` の最初の 1 万件）：`1` で約 805〜832 秒、`16`（各 2 スレッド）で約 174 秒。
- **できる book は、`1` のときと同じにはなりません。** 増える局面と Link の手は同じでも、一部の Leaf の手と評価値が 1〜2 石違うことがあります。また、同時に広げている局面どうしは、互いを見ません（同じ周の 2 つの局面が、同じ新しい局面に行き着くとき、その場では Link が張られません。後の周や、`book fix` で張られます）。
- 同時に動く探索は、それぞれハッシュ表を持つので、メモリが増えます（[9 章](09-large-books.md)）。
- 対象が 1 つだけの周は、1 つずつ広げるのと同じです。対象が少ない周では、同時に動く数も減ります。
- 元の Edax とまったく同じ動作にしたいときは、`book-expand-tasks = 1` にします。

## 7.7 育て方の例

**例 1：自分で研究したい定石を掘る**

```
>play f5d6c3d3c4
>book deviate2 3 6
```

今の盤（`tiger` と呼ばれる定石の局面）から先だけを広げます。この局面が book にまだ入っていないときは、コマンドが何もしないので、先に `book store` を打って、そこまでの手順を book に入れます（`play f5d6c3d3c4`、`book store`、`book deviate2 3 6` の順）。

**例 2：棋譜の束を入れてから、全体を整える**

```
>book add mygames.txt
>init
>book deviate2 2 4
```

**例 3：手順のリストを Edax に打ち継がせる**

```
>book learn openings.txt
```

**例 4：毎日少しずつ広げる（大きな book）**

`config.ini` に、保存の間隔と、同時に行う数を決めておき、起動して `book deviate2 5 5` を打ち、時間が来たら止めます。次の日は、最後の途中経過のファイルから続けます（7.5）。数億局面の book での注意は、[9 章](09-large-books.md)にまとめてあります。

## 7.8 この章のコマンド

| コマンド | 意味 |
|---|---|
| `book store` | 今の対局を book に入れる |
| `book add ファイル` | 棋譜のファイルの対局を book に入れる |
| `book check ファイル` | 棋譜の手を book と比べて数える |
| `book learn ファイル` | 手順のリストを、Edax どうしで打ち継いで book に入れる |
| `book deviate X Y` | 片方の側が X 石まで外れ、評価値が ±Y の範囲の変化を広げる |
| `book deviate2 X Y` | 1 手 X 石まで・合計 Y 石までの失点の変化を広げる（完全読みの Leaf を除く） |
| `book deviate3 X Y` | 同じ（完全読みの Leaf も含む） |
| `book enhance X Y` | 探索の誤差を見込んで、評価値を変えそうな Leaf を広げる |
| `book fill n` | book の局面と局面の間を埋める |
| `book play` | Link のない局面を 1 手ずつ広げる |
