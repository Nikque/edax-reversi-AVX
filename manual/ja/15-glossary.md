# 15. 用語集

[目次](README.md) ｜ 前：[14. コマンドと設定の一覧](14-reference.md)

このマニュアルと、Edax の画面に出てくる言葉です。

| 言葉 | 画面での表記 | 意味 |
|---|---|---|
| 空き | `empties` | 空いているマスの数。対局の最初は 60 |
| 一時ファイル | `book.dat.tmp.番号` | book を保存するとき、いったん全部を書いておくファイル。書き終えてから、本物と入れ替える（[6.6](06-book-basics.md)） |
| 1 周 | round | book を自動で広げるコマンドの、「選ぶ → 広げる → negamax」のひとまわり（[7.3](07-book-learning.md)） |
| 完全読み | solve、exact | 終局まで全部読んで、正確な石差を求めること。確かさ 100% で、深さが空きの数と同じ探索（[5.2](05-search.md)） |
| 棋譜 | game | 対局の手順の記録 |
| 局面 | position、board | 盤の上の石の並びと手番。book では、対称な 8 通りを 1 つにまとめて持つ |
| 確かさ（%） | `@73%` など | 探索の途中で、見込みで枝を打ち切るときの慎重さ。100% は、見込みでの打ち切りをしない（[5.3](05-search.md)） |
| 広げる（展開する） | expand | book の Leaf の手を打った先の局面を、探索して book に足すこと。Leaf が Link になる |
| 最初の局面 | initial position | 今の対局が始まった局面。ふつうは初期局面。`setboard` や棋譜の読み込みで変わる |
| 初期局面 | | オセロのふつうの最初の形（中央に 4 石） |
| 手番 | `Black's turn`・`White's turn` | 次に打つ側 |
| スレッド | task、thread | CPU が同時に進められる仕事の単位。設定 `n-tasks` |
| 石差 | score | 終局したときの、石の数の差 |
| 探索 | search | 先の手を読むこと |
| 定石 | opening | 序盤の決まった手順。`opening` コマンドは、名前の付いた定石の名前を表示する |
| 途中経過のファイル | `.dev2`・`.store` など | book のコマンドが、途中や終わりに、`book-file` の名前に拡張子を足して保存する book（[6.6](06-book-basics.md)） |
| ノード | node | 探索が調べた局面 1 つ。`nodes` はその数、`N/s` は 1 秒あたりの数 |
| ハッシュ表 | hash table | 探索が、調べた局面の結果を覚えておく表。設定 `hash-table-size`（[5.6](05-search.md)） |
| パス | `PS`、`pa` | 打てるマスがないので、手番を相手に渡すこと |
| 評価値 | score | 最後まで最善を尽くしたときの石差の見込み。手番の側から見た数（`+` が良い） |
| 評価データ | `eval.dat` | 中盤の局面に点を付けるためのデータ。これがないと起動しない |
| 深さ（探索） | depth | 何手先まで読むか |
| 深さ（book） | `Depth` | book が何手目までを持つか（[6.4](06-book-basics.md)） |
| プロトコル | protocol | ほかのプログラムとやり取りするための、決まった言葉（GTP・NBoard・XBoard など。[12.1](12-integration.md)） |
| 読み筋 | principal variation、PV | 両者が最善を尽くしたときの手順の予想 |
| 論理 CPU | | OS から見える CPU の数（コアの数、またはその 2 倍） |
| book | book | 序盤〜中盤の局面と評価値をためたデータ（[6 章](06-book-basics.md)） |
| Leaf（リーフ） | leaf、`<手:評価値>` | book の局面で、Link になっていない手のうち、いちばん良い手 1 つ。その先の局面は、まだ book にない |
| level | level | 探索の強さを決める数（0〜60）。空きの数に応じて、深さと確かさが決まる（[5.2](05-search.md)） |
| libedax | | Edax を、ほかのプログラムから関数として呼べるようにしたライブラリ（[12.2](12-integration.md)） |
| Link（リンク） | link、`[手:評価値]` | book の局面で、打った先の局面も book に入っている手 |
| negamax（ネガマックス） | negamax | book の評価値を、下の局面から上の局面へ伝え直す計算 |
| OBF | `.obf` | 問題集のファイルの形式（[10.3](10-files.md)） |
| todo | `todo` | book を自動で広げるコマンドが、その周に選んだ Leaf の数 |
