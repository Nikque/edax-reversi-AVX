# Edax 4.5.5 修正版 ユーザーマニュアル

[English](../en/README.md)

対象の版：**v4.5.5-nikque.13**（`Nikque/edax-reversi-AVX`）。それより前の版では、説明の一部が当てはまりません（その箇所には「v4.5.5-nikque.○ から」と書いてあります）。

Edax は、オセロ（リバーシ）の対局・解析・終盤の完全読み・定石データ（book）の作成ができるプログラムです。このマニュアルは、はじめて使う方が「起動して 1 局打つ」ところから、数億局面の book を育てて保守するところまでを、順に説明します。

## このマニュアルの書き方

- `このような字`は、画面に表示される文字、または入力する文字です。
- 入力の例は、行の頭に `>` を付けて書きます。`>` は Edax が表示する「入力待ち」の印で、自分では打ちません。

  ```
  >hint 3
  ```

  これは「`hint 3` と打って Enter キーを押す」という意味です。
- マスの名前は、横を `A`〜`H`、縦を `1`〜`8` で表します（左上が `A1`、右下が `H8`）。入力は大文字でも小文字でも通ります。
- 画面の盤では、黒石が `*`、白石が `O`、空きマスが `-`、いま打てるマスが `.` です。
- ファイル名の例は Windows 用の実行ファイル（`wEdax-x86-64.exe`）で書いています。Linux・macOS では、実行ファイルの名前だけが違います（[1 章](01-introduction.md)の表）。

## 書いてあることの確かさ

このマニュアルは、v4.5.5-nikque.13 のソースを読み、Windows 版を実際に動かして確かめた内容で書いています。画面の表示の例は、実際の出力です（長いものは途中を省いています）。動かして確かめていないことは、その場所に「確かめていません」と書いてあります。速さとメモリの数字は、どの PC・どの book で測ったかを添えています。**小さい book での数字は、大きい book での見込みにはなりません。**
