# 2. 起動と最初の対局

[目次](README.md) ｜ 前：[1. はじめに](01-introduction.md) ｜ 次：[3. 対局と解析のコマンド](03-playing.md)

この章では、Edax を起動して、Edax を相手に打ち始め、終了するまでを説明します。

## 2.1 用意

1. Release のページから ZIP（`edax-4.5.5-nikque.13.zip` のような名前）をダウンロードして、好きな場所に展開します。日本語や空白を含まない、短い名前のフォルダー（例：`C:\edax`）をおすすめします（book を保存するとき、フォルダーを含めた名前が長すぎると保存できないことがあります。[13 章](13-troubleshooting.md)）。
2. 展開したフォルダーの中の `bin` フォルダーを開きます。実行ファイルと `config.ini`、`data` フォルダー（`eval.dat` と `book.dat`）が並んでいることを確かめます。

**大事な決まり：Edax は、`bin` フォルダーの中から起動します。** Edax は、起動したときの「今いるフォルダー」から `data/eval.dat` を探します。別のフォルダーから起動すると、次のように表示して終了します。

```
Cannot open data/eval.dat
```

## 2.2 起動する

### Windows

次のどちらかで起動します。

- **エクスプローラーから**：`bin` フォルダーの `wEdax-x86-64.exe` をダブルクリックします。黒い画面（コンソール）が開きます。
- **ターミナルから**：`bin` フォルダーを開いた状態で、エクスプローラーのアドレス欄に `powershell` と打って Enter を押すと、そのフォルダーでターミナルが開きます。そこで次のように打ちます。

  ```
  .\wEdax-x86-64.exe
  ```

（このマニュアルの確かめは、ターミナルからの起動で行いました。）

### Linux・macOS

ターミナルで `bin` に移動して、実行ファイルを起動します。展開した直後に「実行できない」と言われたら、実行の許可を付けます。

```
cd edax/bin
chmod +x lEdax-x86-64
./lEdax-x86-64
```

（配布物の ZIP から Linux・macOS で起動する手順そのものは、このマニュアルの作成では試していません。Linux 版の動作は、ソースからビルドしたもので確かめています。）

## 2.3 最初の画面

起動すると、盤と、入力待ちの印 `>` が表示されます。

```
  A B C D E F G H            BLACK            A  B  C  D  E  F  G  H
1 - - - - - - - - 1         0:00.000       1 |  |  |  |  |  |  |  |  | 1
2 - - - - - - - - 2    2 discs   4 moves   2 |  |  |  |  |  |  |  |  | 2
3 - - - . - - - - 3                        3 |  |  |  |  |  |  |  |  | 3
4 - - . O * - - - 4  ply  1 (60 empties)   4 |  |  |  |()|##|  |  |  | 4
5 - - - * O . - - 5    Black's turn (*)    5 |  |  |  |##|()|  |  |  | 5
6 - - - - . - - - 6                        6 |  |  |  |  |  |  |  |  | 6
7 - - - - - - - - 7    2 discs   4 moves   7 |  |  |  |  |  |  |  |  | 7
8 - - - - - - - - 8         0:00.000       8 |  |  |  |  |  |  |  |  | 8
  A B C D E F G H            WHITE            A  B  C  D  E  F  G  H

>
```

**左の盤**が、今の局面です。

| 文字 | 意味 |
|---|---|
| `*` | 黒石 |
| `O` | 白石 |
| `.` | 手番の側が、今打てるマス |
| `-` | 空きマス |

**まん中**は、上半分が黒（BLACK）、下半分が白（WHITE）の情報です。

| 表示 | 意味 |
|---|---|
| `0:00.000` | その色が使った時間（分:秒） |
| `2 discs` | その色の石の数 |
| `4 moves` | その色が打てるマスの数 |
| `ply  1 (60 empties)` | 次が何手目か（1 手目）と、空きマスの数（60） |
| `Black's turn (*)` | 手番（黒番）。白番なら `White's turn (O)` |

**右の盤**は、打った順番です。最初から置いてある石は `##`（黒）と `()`（白）、打った石は「何手目に打ったか」の数字で表示されます。

`>` が出ていれば、Edax は入力を待っています。コマンドを打って Enter を押すと、実行されて、また盤と `>` が表示されます。

## 2.4 Edax と打つ

起動した直後の Edax は、**自分からは打ちません**（人どうしが交互に打つ設定になっています）。Edax を相手にするには、最初に `mode` コマンドで「どちらを Edax が持つか」を決めます。

| 入力 | 意味 |
|---|---|
| `mode 0` | 自分が黒（先手）、Edax が白 |
| `mode 1` | Edax が黒（先手）、自分が白 |
| `mode 2` | Edax どうしで最後まで打つ（見るだけ） |
| `mode 3` | Edax は自分からは打たない（起動した直後の状態） |

自分が黒を持つ例です。`mode 0` と打ってから、打ちたいマス（ここでは `f5`）を打ちます。

```
>mode 0
```

```
WARNING: Unknown command/Illegal move: "e3 "
```

## 2.5 ヒントを見る・待ったをする

**ヒント**：`hint 3` と打つと、今の局面で良い手を 3 つ、評価値つきで表示します（数字を省くと 1 つ）。

```
>hint 3

 depth|score|       time   |  nodes (N)  |   N/s    | principal variation
------+-----+--------------+-------------+----------+----------------------
18@73%  +00        0:00.110      15578834  141625764 c3 D3 c4 F4 c5 B3 c2 E3
18@73%  -01        0:00.000         15137            c4 F4 f6 G5 f3 D3 c3 G6
18@73%  -02        0:00.000          3239            c5 F4 e3 C6 d3 F6 e6 D7
------+-----+--------------+-------------+----------+----------------------
```

1 行が 1 つの手です。大事なのは 2 つの欄です。

- `score`：その手を打ったときの評価値（**手番の側から見た石差**の見込み）。上の例では、c3 が `+00`（引き分けの見込み）、c4 が `-01`（1 石負けの見込み）、c5 が `-02`。
- `principal variation`（読み筋）：その手から始まる、両者が最善を尽くしたときの手順。最初の手が、その行の手です。**この欄では、黒の手が小文字、白の手が大文字**で表示されます。

`depth` の `18@73%` は「18 手先まで、73% の確かさで読んだ」という意味です（[5 章](05-search.md)）。

**待った**：`undo`（または `u`）で、手を戻します。`mode 0`・`mode 1` のとき（Edax が相手のとき）は、**自分の手と Edax の手の 2 手ぶん**が戻ります。戻しすぎたら `redo`（または `r`）でやり直せます。

## 2.6 パスと終局

**パス**：自分の番なのに打てるマスがないとき（まん中の表示が `0 moves`）は、`ps` と打ってパスします。

```
>ps

You play PS
```

Edax の番でパスになるときは、Edax が自分でパスします。

**終局**：両者とも打てなくなると、まん中に `Game over` と勝敗が表示され、盤の下に `*** Game Over ***` と出ます。

```
  A B C D E F G H            BLACK            A  B  C  D  E  F  G  H
1 * O O O O O O O 1         0:00.750       1 |55|56|47|40|48|45|53|54| 1
2 * O * * * * * * 2   25 discs   0 moves   2 |59|46|39|34|16|41|58|57| 2
3 O O O O * O O O 3                        3 |60|38|33|10| 3|11|30|42| 3
4 O O * * O * O O 4       Game over        4 |32|18|12|()|##| 2| 9|43| 4
5 O O * O * O O O 5       White won        5 |31|15| 6|##|()| 1|17|27| 5
6 O * O * O O O O 6                        6 |28|29| 7| 8| 5| 4|26|44| 6
7 * * * O O O O O 7   39 discs   0 moves   7 |37|35|24|14|13|19|49|52| 7
8 O * * * * * * O 8         0:00.000       8 |36|25|21|22|20|23|51|50| 8
  A B C D E F G H            WHITE            A  B  C  D  E  F  G  H

```

この例は、黒 25 石・白 39 石で白の勝ちです。

## 2.7 もう 1 局・終了

| 入力 | 意味 |
|---|---|
| `init`（または `i`） | ふつうの初期局面から、新しい対局を始める |
| `quit`（または `q`、`exit`） | Edax を終了する |

終了するとき、book が変わっていれば、Edax は book をファイル（`data/book.dat`）に保存してから終わります（対局しただけでは、book は変わりません。[6 章](06-book-basics.md)）。

## 2.8 強さを変える

Edax の強さは **level**（0〜60）で決まります。配布物の設定では 18 です。弱くしたいときは小さい数、強くしたいときは大きい数にします。

```
>level 5
```

- level が大きいほど深く読み、時間がかかります。目安と意味は [5 章](05-search.md)にあります。
- level を変えても何も表示されません。今の値は `options` コマンドで見られます（`search level` の行）。
- 起動のたびに同じ level にしたいときは、`config.ini` の `level = 18` の数字を書き換えます（[4 章](04-settings.md)）。

## 2.9 つまずきやすいところ

| 起きたこと | 原因と対処 |
|---|---|
| `Cannot open data/eval.dat` と出て、すぐ終わる | `bin` フォルダーの中から起動していません。`bin` に移動してから起動します |
| 手を打っても Edax が打ってこない | `mode 3`（起動した直後の状態）のままです。`mode 0` か `mode 1` を打ちます。今すぐ 1 手だけ打たせたいときは `go` |
| `Unknown command/Illegal move` | 打てないマスか、綴りの間違いです。打てるマスは、左の盤の `.` です |
| 打てるマスがなくて進まない | `ps` と打ってパスします |
| Edax が考え込んで戻ってこない | level が大きすぎます。`stop` と打つと、考えるのをやめて、そこまでに見つけた手を打ちます。その後は `mode 3`（Edax が自分からは打たない状態）になるので、`level` を小さくしてから、もう一度 `mode 0` か `mode 1` を打ってください |
| 画面が流れて読みにくい | 盤の表示は、コマンドのたびに出ます。`verbose 0` と打つと、盤も探索の表も表示されなくなります（`verbose 1` で元に戻ります） |
