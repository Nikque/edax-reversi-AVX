# 11. 問題を解く・速さを測る

[目次](README.md) ｜ 前：[10. 棋譜と問題のファイル](10-files.md) ｜ 次：[12. ほかのプログラムから使う](12-integration.md)

## 11.1 問題集を解く：-solve

問題のファイル（OBF。[10.3](10-files.md)）の局面を順に探索して、結果を表にします。起動のときのオプションで指定すると、解き終わったら Edax は終了します。

```
wEdax-x86-64.exe -solve ..\problem\fforum-1-19.obf
```

配布物の問題集の最初の 3 問を解いた表示です。

```
 # | depth|score|       time   |  nodes (N)  |   N/s    | principal variation
---+------+-----+--------------+-------------+----------+---------------------
  1|   14   +18        0:00.000         76954            g8 H7 a8 A6 a4 A7 b6
  2|   14   +10        0:00.000         33373            a4 B7 a3 A2 b8 A7 g7
  3|   14   +02        0:00.000        151540            d1 G1 b8 C1 g3 A8 g2
---+------+-----+--------------+-------------+----------+---------------------
three.obf: 261867 nodes in  0:00.000
```

- 1 行が 1 問です。欄の意味は、探索の表と同じです（[5.1](05-search.md)）。`depth` が空きの数と同じで、`@` が付いていなければ、完全読みの結果です（上の 3 問は、空き 14 の局面です）。
- 最後の行は、全部の問題のノード数の合計と、時間の合計です。
- **探索の強さは、設定の `level` です**（配布物の設定では 18。空きが 21 以下の局面は完全読みになります）。空きの多い問題を完全読みで解きたいときは、`-l 60` を付けます。
- よく一緒に使うオプション：`-n 1`（1 スレッド。結果とノード数が毎回同じになる）、`-l 60`、`-h 24`（ハッシュ表を大きく）、`-q`（表を出さず、最後の行だけを出す）、`-vv`（深さが進むたびに 1 行出す）。

  ```
  wEdax-x86-64.exe -solve ..\problem\fforum-40-59.obf -l 60 -n 8 -h 24
  ```
- 問題のファイルに答え（`手:評価値;`）が書いてあると、Edax は、**見つけた手が、答えの最善の手と違うとき**に、行の右に `Erroneous move: D1 expected, with score +2, …` と表示します。完全読みでない level で解くと、これが出ることがあります（下の例は、空き 14 の問題を level 6 で解いたもの）。

  ```
    3|    6   +08        0:00.000         13193            g3 G1 b8 G2          Erroneous move: D1 expected, with score +2, error = …
  ```

実行中の Edax からは、`solve ファイル` で同じことができます。

```
>solve ..\problem\fforum-1-19.obf
```

配布物の問題集（`problem` フォルダー）：

| ファイル | 中身 |
|---|---|
| `fforum-1-19.obf` | 終盤の問題 1〜19 番 |
| `fforum-20-39.obf` | 20〜39 番 |
| `fforum-40-59.obf` | 40〜59 番 |
| `fforum-60-79.obf` | 60〜79 番 |

空きの数は、`fforum-1-19` が 14〜16、`fforum-20-39` が最大 26、`fforum-40-59` が 20〜34、`fforum-60-79` が最大 36 です。空きの多い問題ほど、完全読みに時間がかかります（後ろの 2 つのファイルを `-l 60` で解くと、長い時間が要ります。時間は測っていません）。

## 11.2 速さを測る：bench

Edax に組み込まれた終盤の局面を解いて、速さを表示します。PC の速さの目安や、実行ファイルの種類（標準・`v3`・`v4`）の比較に使えます。

```
wEdax-x86-64.exe -bench 2 -n 2
```

```
 # | depth|score|       time   |  nodes (N)  |   N/s    | principal variation
---+------+-----+--------------+-------------+----------+---------------------
  1|   20   +20        0:00.047       3563782   75825149 a4 C8 a8 D7 c7 G2 a2
  2|   20   -02        0:00.078       8479888  108716513 h7 E6 f8 F7 h6 H3 e8
---+------+-----+--------------+-------------+----------+---------------------
2 positions solved: 12043670 nodes in  0:00.125 (96349360 nodes/s).
```

- `-bench n` の n は、解く局面の数です。実行中の Edax からは `bench n`（n を省くと、全部の局面）。
- 最後の行の `nodes/s` が、1 秒あたりのノード数です。
- 問題が少ないと、時間が短すぎて、数字が安定しません。比べるときは、同じ n・同じ `-n`（スレッドの数）で、何回か測ってください。ほかのプログラムが動いていると、遅く出ます。

## 11.3 局面や手順を数える

今の盤の局面から、何手か先までの手順や局面の数を数えるコマンドです。プログラムの検査用で、ふつうの使い方では要りません。

| コマンド | 意味 |
|---|---|
| `count games d` | d 手先までの手順の数（ハッシュ表を使って速く数える） |
| `perft d` | 同じ数え方で、ハッシュ表を使わない |
| `count positions d` | d 手先までの、違う局面の数 |
| `count shapes d` | d 手先までの、石の形（色を区別しない）の数 |
| `estimate n` | でたらめに n 回打ち進めて、全体の手順の数を見積もる |

初期局面から 6 手先までの例です（1 手目は 4 通り、2 手目までは 12 通り、…）。

```
>count games 6
  ply           moves        passes          wins         draws        losses    mobility        time   speed
   1,               4,            0,            0,            0,            0,    4 -  4,        0:00.000,  …
   2,              12,            0,            0,            0,            0,    3 -  3,        0:00.000,  …
   3,              56,            0,            0,            0,            0,    4 -  5,        0:00.000,  …
   4,             244,            0,            0,            0,            0,    2 -  6,        0:00.000,  …
   5,            1396,            0,            0,            0,            0,    3 -  9,        0:00.000,  …
   6,            8200,            0,            0,            0,            0,    1 - 11,        0:00.000,  …
```

d を大きくすると、時間が急に増えます。起動のときのオプション `-count games 10` でも数えられます。

## 11.4 そのほかの検査用のコマンド

次のコマンドもありますが、このマニュアルを書くにあたって、動かして確かめてはいません（一覧として載せます）。

| コマンド | 組み込みの説明（要約） |
|---|---|
| `microbench` | 主な関数の速さを、CPU のサイクル数で測る |
| `script-to-obf 入力 出力` | 「script」形式の問題のファイルを OBF に変える |
| `select-hard 入力 出力` | 問題集から、難しい問題を選ぶ |
| `wtest ファイル`（`-wtest`） | WTHOR のデータベースの理論値を確かめる |
| `weval ファイル`・`edaxify ファイル` | WTHOR のデータベースを使う検査・変換 |
| `seek 盤`・`mobility n`・`debug-pv 手` | 開発用 |
